## Documentation - Rubric and Submission Generation 
### Description
Domain: Teaching - Set 2, Size: 10

Rub IDs: 0016 to 0025

This dataset is generated using the manual propmt engineering approach.

Each rubric consists of five criteria (C1–C5). Each criterion includes key points and five levels of performance grades: Excellent, Good, Average, Needs Improvement, and Poor.

Student submissions include the questions they used to research information related to the topic, along with responses generated by large language models (e.g., ChatGPT, Gemini, etc.).

Each submission is assessed against the five criteria, and an overall grade is assigned. Feedback is provided for each criterion.

### Data Generation Steps

#### Step 1: Rubric Creation
- A collection of Early Childhood Education essay topics is generated by LLM, CoPilot in particular.
- A generic rubric created from a [free sample rubric](https://www.rcampus.com/rubricshowc.cfm?code=J25WC3C&sp=true&) from iRubric to serve as a sample for LLMs.
- A final rubric for each topic is generated using prompt and the sample rubric.
#### Step 2: Key-points Generation
- A collection of key-points is generated for each grading level using prompt engineering, ChatGPT in particular.

#### Step 3: LLM Questions Generation
- A collection of questions imitating student's submission chain questions is generated for each grading level using prompt engineering, ChatGPT in particular.

#### Setp 4: LLM Answers Collection
- Previously generated questions are fed to LLM, Gemini in particular, to receive a collection of answers for each each grading level using prompt engineering.
- Each level of grading is generated in separate prompt conversation.

#### Setp 5: Final Submisison Generation
- Rubric and collection of answers are fed to the LLM, Gemini in particular, to generate the final submission simulating student writing for each grading level using prompt engineering.
- Each level of grading is generated in separate prompt conversation.

#### Step 6: Feedback Generation
- Rubric and final submission are fed to the LLM, Gemini in particular,to generate individual grading and feedback for each criteria per level using prompt engineering. 
- Each level of grading is generated in separate prompt conversation.
